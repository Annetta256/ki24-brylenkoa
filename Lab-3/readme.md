Лабораторна робота №3: Об'єкти
Мета: закріпити практичні навички роботи з об'єктами в JavaScript: отримання значень властивостей, формування нових об'єктів, роботу з вкладеними структурами та масивами всередині об'єктів.

Файли лабораторної роботи
index.html — підключає JavaScript-файли та дозволяє запустити код у браузері.
run.js — створює тестові об'єкти, викликає функції з lab3.js та виводить результати їх виконання в консоль браузера.
lab3.js — містить умови завдань і функції, які потрібно реалізувати.
Запуск коду
Для запуску лабораторної роботи відкрийте файл index.html у веббраузері, наприклад Chrome або Edge.

Після цього:

Відкрийте DevTools (F12).
Перейдіть на вкладку Console.
У консолі ви побачите результати виконання JavaScript-коду.
Файл index.html спочатку підключає lab3.js, а потім run.js.

Завдання
Файл lab3.js містить 2 завдання на валідацію даних, отриманих із форми.

Завдання 1
Потрібно реалізувати функцію validateForm(formData), яка перевіряє властивості переданого об'єкта та повертає результат у вигляді об'єкта:

{
isValid: false,
errors: ["error1", "error2"]
}
Властивість errors містить загальний масив усіх знайдених помилок.

Завдання 2
Потрібно реалізувати функцію validateFormByFields(formData) з тими самими правилами валідації, але помилки необхідно згрупувати за полями форми.

Приклад:

{
isValid: false,
errors: {
name: ["error1", "error2"],
password: ["error1"]
}
}
Якщо для певного поля немає помилок, його не потрібно додавати до об'єкта errors.

Повний опис правил валідації та очікуваного результату наведено безпосередньо у файлі lab3.js.

Основні зміни потрібно виконувати у файлі:

lab3.js

Файл run.js містить готові тестові дані та код для виклику функцій із lab3.js.

Модифікувати run.js для виконання лабораторної роботи не потрібно, але за необхідності це не забороняється.

Важливо
Не змінюйте:

назви функцій;
кількість і порядок параметрів функцій;
назви файлів.
Змінювати потрібно лише реалізацію функцій у lab3.js, якщо в умові конкретного завдання не зазначено інше.

Це необхідно для того, щоб код із run.js міг коректно викликати та перевіряти ваші функції.
